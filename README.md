Calculadora de gasto de combustível, desenvolvida em Python utilizando o framework StreamLit.

Para uso, baixe o código, ou copie para dentro do PyCharm (IDE de desenvolvimento em Python).
No terminal do PyCharm, instale o framework StreamLit e suas dependências usando: pip install streamlit
Após isso de o comando: streamlit run "nome do arquivo". Ex: streamlit run app.py

Será gerado um link local para teste no seu browser, lembrando que o link é LOCAL, caso queria tornar o link público deve dar deploy no projeto usando a própria streamlit ou algum domínio.
